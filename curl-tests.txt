==============================================================================
JOB PORTAL - CURL TEST FILE
API Gateway: http://localhost:3000   (the ONLY port a client uses)
Routes:      /jobs  -> Jobs service        (internal)
             /applicants -> Applicants service (internal)
==============================================================================

HOW TO RUN
  1. npm install
  2. npm run reset      (restore the starting data so ids match this file)
  3. npm start          (starts both services and the gateway)
  4. Open a second Command Prompt and run the commands below in order.
     Add -i to any command to also see the HTTP status line and headers.
     In PowerShell type curl.exe instead of curl.

Starting data: jobs 1-3 (job 3 is closed), applicants 1-2.
Every error response has the same shape:
  { "success": false, "error": { "status": <code>, "message": "...", "details": ... } }
